# Modular Desktop Installer

> A Qt-based, modular desktop installation wizard for deploying software and configuring system environments.

## 📖 Overview

**Modular Desktop Installer** is a C++/Qt Widgets application designed to streamline the deployment of software. It uses a highly modular architecture (via Qt `.pri` files) to provide a guided wizard interface for installing applications, managing Windows Registry and Environment Variables, restoring databases, and configuring ODBC connections.

## ✨ Features (Verified from source)

- **Modular Architecture** — Installation logic is decoupled into isolated modules (`.pri` files) for easy maintenance and scalability.
- **Software Installation** — Dedicated modules for application deployment (`InstallApp`).
- **System Configuration** — Automated management of Windows Environment Variables (`EnvironmentManager`) and Registry (`Registry`).
- **Database & ODBC Support** — Built-in database restoration (`RestoreDatabase`) and ODBC configuration (`Set_ODBC`) using `Qt SQL`.
- **Dynamic UI** — Features a dynamic `TreeWidget` to navigate through modules, managed by a central `ModuleManager`.
- **Custom Styling & Helpers** — Centralized UI styling via `StyleSheetManager` and reusable components like `ShowMessages` and `ShowFolders`.

## 🧱 Architecture & Code Structure

The project follows a clean, modular design pattern based on Qt's `.pri` include system.

| Layer | Components | Responsibility |
|-------|-----------|----------------|
| **Core UI** | `mainwindow.*`, `main.cpp`, `TreeWidget.*` | Main application window, navigation, and dynamic tree listing. |
| **Management** | `ModuleManager.*`, `modulemanager.*` | Orchestrates the loading and execution of different installation modules. |
| **System Modules** | `Module/Registry`, `Module/EnvironmentManager`, `Module/ShowFolders` | Handles OS-level operations (Registry, Env Vars, File System). |
| **Installation Modules**| `Module/InstallApp`, `Module/RestoreDatabase`, `Module/Set_ODBC` | Handles actual software installation, DB restoration, and ODBC setup. |
| **Styling & Utils** | `StyleSheetManager.h`, `showmessages.*`, `addmadules.ps1` | QSS styling, user notifications, and PowerShell automation. |

> **Note:** The project uses **qmake** (`A.pro`) and relies on `Qt::AA_EnableHighDpiScaling` for high-resolution displays. The `moc_*.cpp` files in the root are automatically generated by Qt's Meta-Object Compiler.

## 🛠️ Tech Stack

- **Language:** C++
- **Framework:** Qt (Qt Widgets, Qt SQL)
- **Build System:** qmake
- **Automation:** PowerShell
- **Target OS:** Windows (due to Registry, Environment Variables, and PowerShell scripts)

## 🚀 Getting Started

### Prerequisites
- Qt 5.x or Qt 6.x (with Qt Widgets and Qt SQL modules)
- C++ Compiler (MSVC, MinGW, or GCC)
- qmake

### Build & Run
```bash
# Clone the repository
git clone https://github.com/mokhtarizahra/installer.git
cd installer

# Build using qmake
qmake A.pro
make      # (or nmake / mingw32-make on Windows)

# Run the application
./installer  # or installer.exe on Windows
